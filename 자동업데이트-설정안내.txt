유설아 팬사이트 — GitHub Actions 자동 업데이트 설정

■ 자동으로 되는 것 (매일 12:00 KST)
  - 유튜브 롱폼 목록 (vod-data.js)
  - 카페·버컴퍼니 사진 (gallery-data.js)
  - 카페 방송 일정 (schedule-data.js)
  - Netlify 사이트 재배포

■ 사이트 접속 시마다 자동 (기존과 동일)
  - 숲 다시보기, 유튜브 쇼츠


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1단계: Git 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  https://git-scm.com/download/win 에서 Git 설치


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2단계: GitHub 저장소 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. https://github.com/new 접속
  2. Repository name 예: yooseola-fansite
  3. Public 또는 Private 선택 후 Create repository


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3단계: 프로젝트를 GitHub에 올리기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PowerShell에서 myWebsite 폴더로 이동 후:

  git init
  git add .
  git commit -m "Initial commit"
  git branch -M main
  git remote add origin https://github.com/본인아이디/저장소이름.git
  git push -u origin main

  ※ GitHub 로그인 창이 뜨면 로그인


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4단계: Netlify 토큰·사이트 ID 준비
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [Personal Access Token]
  1. https://app.netlify.com/user/applications
  2. Personal access tokens → New access token
  3. 토큰 복사 (한 번만 보임 — 메모해 두세요)

  [Site ID]
  1. Netlify에서 이 팬사이트 사이트 선택
  2. Site configuration → General → Site details
  3. Site ID 복사 (예: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5단계: GitHub Secrets 등록
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  GitHub 저장소 → Settings → Secrets and variables → Actions

  New repository secret 두 개 추가:
    이름: NETLIFY_AUTH_TOKEN   값: 4단계에서 복사한 토큰
    이름: NETLIFY_SITE_ID      값: 4단계에서 복사한 Site ID


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6단계: 동작 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  GitHub 저장소 → Actions 탭
  → "Auto update and deploy" 워크플로 선택
  → Run workflow 버튼으로 수동 실행 테스트

  성공하면 Netlify 사이트에 최신 데이터가 반영됩니다.

로컬에서 수동 업데이트 (기존 방식)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
