■ GitHub Secrets (Actions 배포용)
  NETLIFY_AUTH_TOKEN  — https://app.netlify.com/user/applications
  NETLIFY_SITE_ID     — fcf9f461-a571-4392-a4dc-3c4b316a28cc

■ Netlify 환경 변수 (롤링페이퍼 관리자)
  ROLLING_PAPER_ADMIN_KEY — Netlify → Environment variables
  ※ 코드/파일에 비밀번호를 넣지 마세요.

■ 배포 실패: Exposed secrets detected
  Netlify가 빌드 결과에서 비밀값을 찾으면 배포를 막습니다.
  1) admin-config.mjs 같은 파일에 비밀번호가 없는지 확인
  2) Netlify Deploy 로그에서 어떤 값이 걸렸는지 확인
  3) ROLLING_PAPER_ADMIN_KEY 를 Secret으로 등록했다면
     빌드 출력에 값이 섞일 수 있음 → 일반 변수로 바꾸거나
     Site env: SECRETS_SCAN_SMART_DETECTION_ENABLED = false
  4) netlify.toml 에도 SECRETS_SCAN_ENABLED=false 가 설정되어 있음
  5) GitHub Actions → Auto update and deploy → Run workflow

■ 일정이 안 바뀔 때
  - Actions의 "Update schedule" / "Auto update and deploy" 로그에서
    "Deploy to Netlify" 단계가 실패하면 사이트는 갱신되지 않습니다.
  - 카페 일정표 수정 후 최대 1시간(또는 deploy 3시간) 뒤 반영됩니다.
  - 즉시 반영: powershell -File update-schedule.ps1 후 push
  - (선택) Netlify Build hook URL → GitHub Secret NETLIFY_BUILD_HOOK

■ 로컬 수동 업데이트
