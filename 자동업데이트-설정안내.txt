유설아 팬사이트 — GitHub Actions 자동 업데이트 설정

■ 자동으로 되는 것
  - 유튜브 롱폼 목록 (vod-data.js)
  - 카페·버컴퍼니 사진 (gallery-data.js)
  - 카페 방송 일정 (schedule-data.js) — 매시 15분
  - 추억의 플레이리스트 (memory-playlist-data.js)
  - Netlify 사이트 재배포

■ 사이트 주소 (Netlify)
  https://yooseolafansite.netlify.app/

  ※ 롤링페이퍼·갤러리 API 등 Netlify Functions는 이 주소에서만 동작합니다.

■ 사이트 접속 시마다 자동 (기존과 동일)
  - 숲 다시보기, 유튜브 쇼츠

1단계: GitHub Secrets (Netlify 배포용, 필수)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  GitHub 저장소 → Settings → Secrets and variables → Actions

  NETLIFY_AUTH_TOKEN
    https://app.netlify.com/user/applications → Personal access tokens

  NETLIFY_SITE_ID
    Netlify → Project details → Project ID (Site ID)
    예: fcf9f461-a571-4392-a4dc-3c4b316a28cc

  GitHub → Actions → "Auto update and deploy" → Run workflow

  성공하면 https://yooseolafansite.netlify.app/ 에 반영됩니다.
